# Saves and rooms as 0.3.3 wrote them

Generated by the published 0.3.3 code (f00926d4), never edited by hand: GreedyBots played the two local games
from the start screen's setups, and the files are what `LocalSaveStore`, the "last" setup preference and
`Room.wire()` wrote. `expected.tsv` holds what 0.3.3 showed for each save: the state hash after the replay, and the
players' names and colours by engine player.

OldSavesTest checks that this version reads every one of them: a local game resumes at the same position with the
same names and colours, the remembered setup comes back, and a 0.3.3 room is refused with the update message.
Add a folder like this one for each release that changes a save, setup or room format.
