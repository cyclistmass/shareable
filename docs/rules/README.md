# Rules

How Working German Board Game plays, written from the engine (`engine/`), so these pages describe what the app
actually does. Where the app settles a question the table often argues about, the page says so under
**How the app plays it**.

- [base.md](base.md): the base game, 2 to 4 players, 10 points.
- [chivalry.md](chivalry.md): Age of Chivalry, 3 or 4 players, 13 points: commodities, town upgrades, knights and the Raiders.
- [cards.md](cards.md): every card, its name, what it does and how many are in the deck.

All names, rules text and card text here are our own. An original game, not affiliated with or endorsed by any other
game's publisher (see the README's Trademarks section). `app/src/test/.../OurNamesTest.kt` fails the build if a page
here, a card or a line in the game log uses another game's names.

## Our names

| Thing | Our name |
|---|---|
| Resources | Timber, Clay, Fleece, Grain, Stone |
| Terrains | Woodland, Clay pit, Meadow, Grainfield, Quarry, and the desert, which makes nothing |
| Pieces | road, Homestead (1 point), Town (2 points) |
| The thief piece | the Bandit |
| Bought cards (base game) | Fortune cards: Sentinel, Windfall, Corner the Market, Trailblazers, Landmark |
| Awards (base game) | Grand Highway (the longest unbroken run of 5+ roads), Strongest Watch (3+ Sentinels) |
| Age of Chivalry commodities | Parchment, Fabric, Silver |
| Upgrade tracks and progress decks | Guilds, Crown, Academy |
| The invaders | the Raiders |
| A level-4 town | Capital |
| Town defences | Ramparts |
| The Raiders' reward card | Defender of the Realm |
| The Peddler's piece | the Trader |
